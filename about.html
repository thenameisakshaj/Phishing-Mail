Mini Project 1 · Phishing Mail

Transparent detection for safer learning.

PhishGuard is a student-friendly, local Flask application that converts common phishing warning signs into an explainable heuristic score. It demonstrates defensive thinking without sending messages, visiting links, or handling files.

Project objective

What this application teaches

The project separates an email into sender, content, URL, and attachment-filename signals. Each triggered rule contributes visible points and a practical recommendation, so learners can explain both the result and its limitations.

  • Recognise social-engineering patterns.
  • Read sender and destination domains carefully.
  • Understand risky filename extensions.
  • Apply independent verification habits.
Safety boundaries

Intentionally not included

  • Email sending or account integration
  • Credential forms or login-page imitation
  • URL requests, DNS lookups, or website scanning
  • File uploads, downloads, or execution
  • History, tracking, analytics, or authentication
  • Production-grade detection claims
